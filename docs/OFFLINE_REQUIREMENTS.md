## PREPARATION PHASE (one-time, requires network)

These steps are performed BEFORE going offline. After preparation, the system runs without any network.

### 1. Install Python dependencies

```powershell
C:\Python311\python.exe -m pip install rasterio faiss-cpu pyyaml pydantic pillow
C:\Python311\python.exe -m pip install open-clip-torch   # for RemoteCLIP
# torch and opencv-python already installed
```

All wheels must be downloaded and cached. After this step, pip works offline.

### 2. Download embedding model weights (RemoteCLIP)

```powershell
C:\Python311\python.exe -c "
from huggingface_hub import hf_hub_download
hf_hub_download(
    repo_id='chendelong/RemoteCLIP',
    filename='RemoteCLIP-ViT-B-32.pt',
    local_dir='models/local',
)
print('RemoteCLIP-ViT-B-32.pt staged to models/local/')
"
```

Expected file: `models/local/RemoteCLIP-ViT-B-32.pt` (~350MB)

### 3. Stage imagery

```
data/sample/              ← test synthetic GeoTIFFs (generated by scripts/make_test_geotiff.py)
data/<mission>/           ← real Sentinel-2, Landsat, organiser-provided imagery
```

All GeoTIFFs must be present locally before ingest. No remote tile or imagery API is called at runtime.

### 4. Build the index (ingest)

```powershell
# Single file
C:\Python311\python.exe -X utf8 scripts\ingest.py --file data\sample\scene.tif

# All TIFFs in a directory (when batch script is added in Phase 5)
# C:\Python311\python.exe scripts\ingest_dir.py --dir data\sentinel2\
```

Output:
- `data/faiss_index/faiss_flat.index` — vector index
- `data/faiss_index/faiss_idmap.json` — tile_id mapping
- `data/terrae_metadata.db` — SQLite metadata

## OFFLINE EXECUTION (no network required)

All of the following must work without internet access.

### Start

No server to start for the CLI-based MVP. Just run the scripts.

```powershell
# Set offline env vars (the system sets these, but you can add them manually)
$env:TRANSFORMERS_OFFLINE = "1"
$env:HF_HUB_OFFLINE = "1"
$env:HF_DATASETS_OFFLINE = "1"
```

### Query (text → ranked tiles)

```powershell
C:\Python311\python.exe -X utf8 scripts\query.py --text "dense urban area" --top-k 10
C:\Python311\python.exe -X utf8 scripts\query.py --text "flooded farmland" --top-k 5
```

### Ingest new imagery

```powershell
C:\Python311\python.exe -X utf8 scripts\ingest.py --file data\new_scene.tif
```

Duplicate scenes (same file hash) are automatically skipped.

### Verify offline capability

```powershell
# Block all outbound connections conceptually, then run tests:
$env:TRANSFORMERS_OFFLINE = "1"
$env:HF_HUB_OFFLINE = "1"
C:\Python311\python.exe -m pytest tests/ -v
# Expected: 70/70 passed (all tests use only local data and local packages)
```

## What CANNOT happen at runtime

| Blocked action | Why |
|---------------|-----|
| `huggingface_hub.hf_hub_download()` | Model weights must be pre-staged |
| `requests.get()` to any external API | No OpenAI / Gemini / Claude API calls |
| Remote map tile fetch | No OpenStreetMap or basemap CDN |
| Online geocoding | No Nominatim or Google Maps |
| Copernicus / Bhoonidhi API | Data must be pre-downloaded |
| pip install at runtime | All packages pre-installed |
